# EEG Thought Decoder using CNN, LSTM and Transformer

## Overview
This project decodes EEG brain signals using a hybrid deep learning architecture combining CNN, LSTM, and Transformer networks.

## Technologies Used
- Python
- TensorFlow / PyTorch
- CNN
- LSTM
- Transformer
- EEG Signal Processing

## Dataset
Kara One EEG Dataset

## Features
- EEG preprocessing
- Feature extraction
- Sequential learning
- Attention-based decoding

## Future Improvements
- Real-time decoding
- Improved transformer architecture
